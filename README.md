# TrendSeller Blog Platform

A modern blogging and product discovery platform where sellers can publish product blogs, discover trending products, and help buyers stay updated with market trends.

---

# 🚀 Overview

TrendSeller is a platform designed for sellers, entrepreneurs, and creators to showcase products through engaging blog posts.

The platform helps:
- Sellers understand what products are trending
- Buyers discover popular products
- Businesses promote products using blog content

---

# ✨ Features

## 🛍 Product Blogging
Sellers can:
- Upload product images
- Create blog posts about products
- Add pricing and product details
- Organize posts by category

## 📈 Trending Products
- Discover most viewed products
- Explore trending categories
- See popular sellers

## 🔍 Smart Search
Search by:
- Product name
- Seller name
- Category
- Trending keywords

## 👤 Seller Profiles
Each seller gets:
- Custom profile page
- Product listings
- Blog history
- Followers and engagement stats

## 💬 Community Features
Users can:
- Like posts
- Comment on blogs
- Share products
- Save favorites

# ⚙️ Installation

## 1. Clone the Repository

```bash
git clone https://github.com/your-username/trendseller.git
```

---

## 2. Navigate into the Project

```bash
cd trendseller
```

---

## 3. Install Frontend Dependencies

```bash
cd frontend
npm install
```

---

## 4. Install Backend Dependencies

```bash
cd ../backend
npm install
```

---

# ▶️ Running the Project

## Start Backend

```bash
cd backend
npm run dev
```

## Start Frontend

```bash
cd frontend
npm start
```
